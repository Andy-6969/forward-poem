"Forward", an original short poem about permission: a guide dog that refuses a command at the curb, and what it means to be given someone who can tell you no. `main.ts` writes it to `/output/entry.txt`, the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
